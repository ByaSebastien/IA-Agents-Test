# Mon profil – Camille Durand, développeuse front-end à Bruxelles

## Description courte
Cette page présente Camille Durand, une développeuse front-end basée à Bruxelles. Elle présente son profil, ses compétences, ses projets et ses moyens de contact.

## Fichiers du projet
- `index.html` : le fichier HTML principal de la page.
- `style.css` : le fichier CSS pour le style de la page.
- `assets/avatar-camille.webp` : l'image de profil de Camille.

## Fonctionnalités d'accessibilité
- **Lien d'évitement** : un lien `<a class="skip-link" href="#main">Aller au contenu</a>` permet aux utilisateurs de sauter directement au contenu principal.
- **Structure des titres** : un seul `<h1>` (le nom), des `<h2>` pour les sections, des `<h3>` pour les projets, sans saut de niveau.
- **Texte alternatif de l'avatar** : l'image de profil a pour `alt` « Portrait illustré de Camille Durand, souriante, cheveux bruns bouclés et lunettes rondes ».
- **Thème clair/sombre automatique** : via `prefers-color-scheme` dans `style.css` (palette claire par défaut, palette sombre si le système le demande).

## Comment l'ouvrir
Ouvrez simplement le fichier `index.html` avec un navigateur web. Aucune dépendance externe n'est nécessaire.

## Note importante
L'adresse e-mail et les liens (example.com, GitHub, LinkedIn) sont fictifs.
